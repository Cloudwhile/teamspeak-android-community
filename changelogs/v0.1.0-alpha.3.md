> [!WARNING]
> **Experimental Alpha — TS6 Live Streaming**: Screen sharing and camera live broadcasting/viewing over TeamSpeak 6 WebRTC are currently in **unstable Alpha testing**. Requires a TeamSpeak 6 server (`6.0.0-beta+`); P2P ICE/NAT traversal, hardware video codec negotiation, and stream stability may fail or behave inconsistently across different networks and devices.

### Added

- **Portable TSCC Configuration Export & Restore**: Added **Export & Restore TSCC Config** in Settings to back up and migrate user identities (`.ini` keys & security levels), server bookmarks & labels, default preferences, and per-member mixer volumes in a single `.json` file, with optional password encryption, local file save/open, and system share support.
- **Share-to-Join & Enhanced `tscc://` Deep Links**: Added support for joining servers directly by sharing invite text to TSCC, alongside browser `intent://` links, `/channel` paths, `#fragment` channel targets, bookmark labels, and an option to save external invite links directly to Server Bookmarks.

### Changed

- **Dedicated `tscc://` Invite Link Scheme**: Migrated server invite deep-link handling and one-tap link copying across Bookmarks, Room Details, and BBCode chat links to the dedicated `tscc://` scheme for reliable app routing on Android.
- **UI Copy & Error Message Polish**: Refined bilingual interface descriptions, onboarding permission guidance, backup prompts, and connection error messages for clarity.

### Fixed

- **Onboarding Step Navigation**: Fixed a state race where tapping **Next · Voice & Perms** on Step 2 could complete and exit the first-run onboarding wizard before Step 3.
- **Single-Line Input Field Touch Area**: Fixed an issue where long placeholder hints in single-line text fields wrapped onto a second line and reduced the tappable input area.
