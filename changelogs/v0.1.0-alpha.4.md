> [!WARNING]
> **Experimental Alpha — TS6 Live Streaming**: Screen sharing and camera live broadcasting/viewing over TeamSpeak 6 WebRTC are currently in **unstable Alpha testing**. Requires a TeamSpeak 6 server (`6.0.0-beta+`); P2P ICE/NAT traversal, hardware video codec negotiation, and stream stability may fail or behave inconsistently across different networks and devices.

### Added

- **Automatic Update Package Cleanup**: Added post-upgrade (`MY_PACKAGE_REPLACED`), app startup, foreground resume, and update-check cache cleanup to automatically remove installed or incomplete `.apk` packages from `cache/updates/`.
- **Bookmark Search Empty State**: Added a dedicated empty-result card with a one-tap **Clear Search** action when filtering server bookmarks returns no matches, alongside password visibility controls for default sub-channel passwords.

### Changed

- **Accurate Local Device Info on Self Profile**: Viewing your own member card in a voice channel now displays your actual Android OS version and TSCC client version instead of wire handshake signature metadata.
- **Light Mode Contrast & Unified Controls**: Improved Light Mode semantic accent contrast for security badges and status indicators, unified capsule switches across room member sheets, and refined connection timeout, port refusal, network unreachable, and DNS error messages.

### Fixed

- **Modal Dialogs, Soft Keyboard Insets & Narrow-Screen Layouts**: Fixed an empty secondary button appearing in single-action modals, added soft-keyboard (`IME`) and system-bar insets to dialogs and fullscreen live stream overlays, prevented narrow-screen clipping on the bottom voice dock, and fixed title truncation in Settings.
