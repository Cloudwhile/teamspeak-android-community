> [!WARNING]
> **Experimental Alpha — TS6 Live Streaming**: Screen sharing and camera live broadcasting/viewing over TeamSpeak 6 WebRTC are currently in **unstable Alpha testing**. Requires a TeamSpeak 6 server (`6.0.0-beta+`); P2P ICE/NAT traversal, hardware video codec negotiation, and stream stability may fail or behave inconsistently across different networks and devices.

> [!IMPORTANT]
> **One-Time Signing Certificate Migration (`alpha.1` -> `alpha.2`)**: Starting with `v0.1.0-alpha.2`, official releases use a fixed release signing certificate. If upgrading from `v0.1.0-alpha.1` reports an Android **package signature conflict**, please export your `.ini` identity key in **Settings -> Identity Keys**, uninstall `alpha.1`, and install `alpha.2` once. All subsequent releases will upgrade seamlessly in-place.

### Added

- **First-Run Onboarding Wizard**: Added a 3-step initial setup flow covering live display language & dark/light theme preview, default nickname & desktop `.ini` P-256 identity import, and voice trigger mode (`VAD` / `PTT` / `Continuous`) with contextual runtime permissions.
- **In-Room Server Information Sheet**: Tapping the room header now opens a live server telemetry sheet displaying online/reserved slots, ping & packet loss, uptime, security level requirement, server platform/version, voice encryption mode, Server UID, BBCode host announcement & welcome message, and one-tap address or invite link sharing.
- **Member & Group Management Sheet**: Tapping or long-pressing any channel member (or yourself) opens a unified detail and action sheet supporting client platform/version/online/idle/ping inspection, multi-select Server Group & Channel Group assignment, Grant/Revoke Talk Power, bio editing, and self server nickname / Channel Commander / Away (AFK) controls.
- **Group & Client Icon Rendering**: Automatically downloads server group, channel group, and client icons, transcodes desktop `.ico` containers (embedded PNG and 1/4/8/24/32-bit BMP DIB) losslessly to PNG, and renders `[Prefix]`/`[Suffix]` group tags alongside ordered inline icon badges.
- **Bilingual Rich Release Notes Popup**: Automatically presents a structured Markdown release notes dialog (in English and Simplified Chinese) immediately upon detecting a new version.

### Changed

- **Streamlined Settings Hub**: Reorganized Settings into 6 focused navigation entries with dedicated sub-screens for Voice & Audio, Language & Appearance, and About TSCC (consolidating update checks, startup auto-check toggle, `NEW` version badge, and Open Source Licenses).
- **On-Demand Permission Prompts**: Moved runtime permission requests from initial launch to guided onboarding and contextual actions.

### Fixed

- **Instant Disconnect on Task Removal**: Synchronously flushes encrypted `clientdisconnect` over UDP and awaits server acknowledgment when swiping TSCC away from Recent Apps, eliminating ghost sessions stuck until server UDP timeout.
- **Android 12+ Cold-Start Splash Icon**: Replaced the unmasked square adaptive icon flash on Android 12+ cold start with a rounded vector splash emblem that transitions seamlessly into the launch wave animation.
- **Localization & Regional Format Improvements**: Improved English and Simplified Chinese UI strings, dynamic notification channel localization on language switch, bilingual WebRTC & connection status messages, English pluralization, TalkBack labels, and locale-safe parsing.
